# Emmanuel Ishang — Product Designer Portfolio

A modern, responsive personal portfolio website showcasing selected works, in-depth product design case studies, interactive UI experiments, and personal insights.

🔗 **Live Website**: [https://emmyrazy.github.io/portfolio/](https://emmyrazy.github.io/portfolio/)

---

## 🚀 Featured Projects & Case Studies

- **[Flyrinzo](flyrinzo.html)** — AI-powered social media management platform for small businesses and entrepreneurs, automating content creation, scheduling, analytics, and community engagement.
- **[Mystra](mystra.html)** — Creator-to-business platform helping creators connect with brands for verified campaign opportunities with transparent rate cards and milestone workflows.
- **[Traclet](traclet.html)** — Modern shortlet marketplace connecting guests, hosts, and verified local experience providers with calendar management and trust verification.
- **[Sender Logic](senderlogic.html)** — On-demand logistics and delivery platform featuring real-time route visibility, fast package tracking, and the "swipe to go live" courier interaction.
- **[Playground](playground.html)** — Visual design experiments, mobile interfaces, Web3 token swap prototypes, and character illustrations.

---

## 🛠️ Tech Stack & Design System

- **Semantic HTML5** & **Modern CSS3** (CSS Custom Properties, Responsive Grid & Flexbox)
- **Fluid Typography**: Sora variable font
- **Glassmorphism UI**: Floating liquid-glass pill navigation bar
- **Form Handling**: Integrated Web3Forms with asynchronous validation and feedback toast
- **Performance**: High-definition 2048px retina-optimized assets with lazy loading and zero layout shifts

## 💻 Local Development

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/Emmyrazy/portfolio.git
cd portfolio
open index.html
```

Or run a local HTTP server:

```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000`.
